# 화성인사이드 v6.4 — 메인 의장카드 + 회원 상세프로필 DOM 업그레이드

이번 버전은 v6.3을 기준으로 다음 두 영역만 구조적으로 확장합니다.

## 1) 메인 의장 인사말 카드
- 메인의 다른 레이아웃은 유지
- 의장 영상과 인사말 카드 높이 정렬 유지
- 인사말 카드 내부를 `의장 사진 + 직책/이름 + 인사말 + 서명`으로 재구성
- 어드민 `/admin/home`에서 이름, 직책, 인사말, 사진, 영상 URL/썸네일, 서명을 각각 관리
- 의장 인사말 사진 권장 960×1200px(4:5), 최소 허용 720×900px
- 기존 1200×1500 강제 제한을 완화하여 실제 세로형 인물 사진이 등록되도록 수정

## 2) 회원 상세페이지
- 마스터 이미지가 아닌 실제 DOM/DB 기반
- 회원 `/account`에서 아래 정보를 직접 입력/수정
  - 프로필 이미지, 이름, 직업/직책, 한 줄 소개
  - 나이, 성별, 이메일, 최종학력, 활동지역
  - 전문분야/태그, 개인정보 소개
  - 유튜브 URL/썸네일
  - 경력/이력
  - 6개 강점 점수(분석/공감/연결/성장/창의/실행)
- 입력 완료 후 `/members/[id]` 상세페이지에 자동 반영
- 관리자 `/admin/members`에서도 같은 상세 정보를 수정 가능
- 상세페이지 구성: 프로필 헤더 → 영상/철학 → 소개/경력 → 추천 멤버 → 강점 레이더 → 연결 CTA
