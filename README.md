# 화성인사이드 v2 - DOM 구조 전환 1차

이번 버전의 목적은 **디자인 완성도가 아니라 구조 전환**입니다.

메인페이지는 더 이상 한 장의 웹마스터 이미지 + 투명 클릭맵으로 동작하지 않습니다.
정참시처럼 실제 React/HTML/CSS 요소와 데이터로 구성됩니다.

## 메인 구조
- `SiteHeader` : 실제 로고/메뉴 링크
- `Hero` : 실제 제목/설명/버튼 + 장식 이미지
- `ChairSection` : 실제 영상 썸네일 자산 + 박인식 사진 + 실제 인사말 텍스트
- `FeaturedSection` : `data/members.js`에서 Top 10을 읽어 카드 렌더링
- `NewsSection` : 실제 공지 카드와 링크
- `MembersSection` : 멤버 데이터에서 20명을 렌더링
- `SiteFooter` : 실제 텍스트/링크 기반 푸터

## 실제 인물
- Top 10 1번: 박인식 / 영화감독
- Top 10 2번: 김광선 / 기획·마케팅
- 두 사람은 원본 고해상도 사진 자산을 사용합니다.

## 기존 페이지
리스크를 줄이기 위해 이번 1차에서는 아래 페이지를 기존 승인 마스터 방식으로 유지합니다.
- 박인식 / 김광선 상세페이지
- 공지 & 뉴스 목록
- 공지 & 뉴스 상세

메인 구조가 안정화되면 같은 방식으로 순차 전환합니다.

## 반응형 기반
메인은 DOM 구조이므로 PC/태블릿/모바일 CSS breakpoint를 이미 포함했습니다.
디자인 세부 조정은 다음 단계에서 승인 마스터를 기준으로 맞추면 됩니다.
