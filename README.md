# Hwaseong Inside v3 - Clean Web Structure

메인페이지를 기존 마스터 이미지 방식에서 완전히 분리한 구조 전환 버전입니다.

## 핵심
- 메인페이지 마스터 이미지 사용: 0
- 메인 클릭맵 사용: 0
- Header / Hero / 의장영역 / Featured 10 / 공지&뉴스 / 40인 / Footer 모두 실제 HTML·CSS·React 요소
- 의장 영상 썸네일은 CSS 기반 독립 비주얼
- 공지&뉴스 이미지는 CSS 기반 독립 비주얼
- 박인식 / 김광선은 실제 원본 사진 파일을 개별 자산으로 사용
- 모바일 반응형 구조 포함

## 현재 우선순위
이번 버전은 디자인 2순위, 구조 안정성 1순위입니다.
기존 확정 레이아웃의 섹션 순서와 비율만 유지하고, 이후 디자인을 정교하게 입히는 기반입니다.
