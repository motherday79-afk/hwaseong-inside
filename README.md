# Hwaseong Inside - real content v1

이번 버전은 기존 메인/상세/공지 마스터 구조를 유지한 채, 실제 인물 및 실제 문구 일부를 반영한 웹 적용본입니다.

## 반영된 실제 콘텐츠
- 메인페이지 의장 인사 영역: **박인식 / 의장·영화감독** 반영
- 메인페이지 Featured 10 중 1번 멤버: **김광선 / 기획·마케팅** 반영
- 멤버 상세페이지: **김광선 프로필 마스터 이미지**로 교체
- 공지&뉴스 목록/상세: 기존 승인 마스터 유지

## 구조
- `/` : 메인 마스터 이미지 + 투명 클릭맵
- `/members/[id]` : 김광선 프로필 마스터 이미지 + 투명 클릭맵
- `/notice-news` : 공지&뉴스 목록 마스터 이미지 + 투명 클릭맵
- `/notice-news/[id]` : 공지 상세 마스터 이미지 + 투명 클릭맵

## 적용 방법
1. 압축 해제
2. GitHub `hwaseong-inside` 저장소 루트에 전체 덮어쓰기
3. Commit changes
4. Vercel 자동 배포 확인
