# Hwaseong Inside v4 — Admin Foundation

화성인사이드의 실제 웹 구조에 관리자 시스템을 추가한 1차 기반 버전입니다.

## 관리자 주소
- `/admin` — 대시보드
- `/admin/members` — 회원 관리
- `/admin/featured` — Featured Top10 관리
- `/admin/home` — 메인/의장 관리
- `/admin/news` — 공지 & 뉴스 관리
- `/admin/media-guide` — 이미지 등록 규격
- `/admin/settings` — 사이트 공통 설정

## 관리자에서 관리 가능한 영역
### 메인
- 히어로 타이틀 / 설명 / 버튼
- 히어로 비주얼
- 의장 이름 / 직책 / 인사말
- 의장 사진 / 영상 썸네일 / 영상 URL / 서명
- Featured 10 노출 멤버 / 순서
- 공지 & 뉴스 카드
- 회원 리스트
- 푸터 연락처

### 회원
- 프로필 사진
- 이름 / 직업·직책 / 나이 / 성별
- 이메일 / 최종학력 / 활동지역
- 해시태그 / 개성있는 소개
- 경력 · 이력

## 이미지 등록 기준
- 회원 프로필 원본: **1200 × 1200px / 1:1**
- 의장 인사말 사진: **1200 × 1500px / 4:5**
- 의장 영상 썸네일: **1600 × 900px / 16:9**
- 공지 & 뉴스 대표이미지: **1200 × 675px / 16:9**
- 메인 히어로 비주얼: **1600 × 1200px / 4:3**
- 의장 서명: **1200 × 400px / 투명 PNG**
- 사이트 로고: **SVG 우선 / PNG는 1200 × 300px 이상**

## 회원 이미지 자동 연동 원칙
회원이 가입할 때 1200×1200 프로필 원본을 한 번 등록합니다.
이 한 장을 회원 DB의 대표 프로필로 저장하고 다음 영역에서 공통 사용합니다.

`가입 → 프로필 원본 등록 → 회원 DB → Top10 / 40인 / 상세페이지 자동 연동`

페이지별로 같은 사람의 이미지를 따로 제작하지 않습니다.
표시 영역에서는 CSS `object-fit: cover`와 이미지 위치값만 다르게 사용합니다.

## v1 저장 방식
현재 관리자 v1은 구조와 UX 검증을 위해 브라우저 `localStorage`에 변경 사항을 저장합니다.
같은 브라우저에서 관리자에서 수정한 메인/회원/뉴스 정보는 실제 메인페이지에 반영됩니다.

다음 백엔드 단계에서 localStorage 저장부를 DB/API로 교체하면 다음이 가능해집니다.
- 여러 관리자 간 데이터 공유
- 로그인한 회원의 본인 프로필 수정
- 관리자 전체 회원 수정 권한
- 회원가입 시 이미지 업로드 및 자동 프로필 생성
- 변경 이력 / 승인 / 공개 상태 관리
- 이미지 스토리지 원본 보존 및 자동 리사이즈

## 권한 목표
- 최고 관리자: 전체 사이트와 모든 회원 수정
- 운영 관리자: 회원 검수 / 메인 / 공지 관리
- 일반 회원: 본인 프로필과 사진만 수정
