# Hwaseong Inside - real content v1.1 exact

이 버전은 사용자가 직접 승인한 **정확한 메인 마스터 이미지**와 **정확한 상세 마스터 이미지**를 그대로 적용한 교정본입니다.

## 핵심 교정
- 메인 마스터: 사용자가 승인한 이미지 그대로 적용
  - 박인식 의장 사진/문구 유지
  - Featured 10 첫 번째 인물만 김광선으로 반영된 상태 유지
- 상세 마스터: 사용자가 승인한 김광선 상세 이미지 그대로 적용
- 공지 & 뉴스 마스터: 기존 승인본 유지
- 클릭 포인트 구조: 기존과 동일한 투명 클릭맵 유지

## 적용 방법
1. 압축 해제
2. GitHub `hwaseong-inside` 저장소 루트에 전체 덮어쓰기
3. Commit changes
4. Vercel 자동 배포 확인
