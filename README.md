# 화성인사이드 v1

가볍게 디자인/흐름을 확인하기 위한 정적 Next.js 프로토타입입니다.

## 실행
```bash
npm install
npm run dev
```
브라우저에서 http://localhost:3000

## 포함
- 메인 페이지
- 50명 샘플 회원 데이터
- Featured 10
- 일반 멤버 20명 우선 노출 + 더보기
- 회원 상세 페이지
- Gold / Platinum 배지
- 매칭 멤버 5명 추천 UI
- 6각형 강점 레이더
- 반응형

## 아직 제외
- Supabase / DB
- 로그인
- 실제 결제
- 게시판 CRUD
- 실제 YouTube 영상
- 실제 회원 이미지 업로드

UI 확정 후 2단계에서 붙이는 구조입니다.
