# 화성인사이드 v7.10 — Profile Editor UX

기준본: v7.9 연락처/개인정보 보호 버전

## 이번 수정
- 회원 본인 `/account` 경력: 추가 / 삭제 / 위로 / 아래로 순서 변경
- 관리자 `/admin/members` 경력: 추가 / 삭제 / 위로 / 아래로 순서 변경
- 경력 저장 시 현재 화면 순서가 `sort_order`로 그대로 저장
- 전문분야/해시태그 입력 UX 수정
  - `마케팅,기획,디자인`
  - `영화/문화/기획`
  - `#마케팅 #종교자`
  형식 모두 입력 가능
- 회원 본인과 관리자 입력창 아래에 입력 예시 안내 추가
- 계정&권한 관리의 해시태그 입력도 동일 규칙으로 정리

## DB
추가 SQL 실행 없음. 기존 `members.tags`, `careers.sort_order` 구조를 그대로 사용합니다.
