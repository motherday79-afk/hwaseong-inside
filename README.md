# 화성인사이드 v2

메인페이지와 회원 상세페이지를 포함한 Next.js 프로젝트입니다.

## 실행

```bash
npm install
npm run dev
```

## 배포

GitHub 저장소의 루트 파일을 이 프로젝트로 교체한 뒤 push하면, 연결된 Vercel 프로젝트에서 자동 배포됩니다.

## 현재 범위

- 메인페이지
- Featured 10
- 공지 & 뉴스
- 일반 멤버 20명 우선 노출 + 더보기
- 회원 상세페이지
- Gold / Platinum 회원등급
- 추천 매칭 멤버 5명
- 6각형 강점 레이더
- 반응형 UI

DB, 로그인, 결제, 관리자 페이지는 추후 단계에서 연결합니다.
